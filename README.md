# Prashant Dahiya - 3D VR Portfolio

This is a modern, 3D interactive portfolio website built with **HTML**, **CSS**, **JavaScript**, **Three.js**, and **Vite**.

## Features
- **3D Interactive Background**: A rotating neural/constellation network built with Three.js that reacts to mouse movement.
- **Glassmorphism UI**: Modern, semi-transparent cards with blur effects.
- **Cyberpunk / VR Aesthetic**: Neon cyan and magenta color palette.
- **Responsive**: Fully optimized for mobile and desktop.

## How to Run

1.  Open this folder in your terminal.
2.  Install dependencies (if not already):
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
4.  Open the local URL (usually `http://localhost:5173`).

## Build for Production
```bash
npm run build
```
The output will be in the `dist` folder.
